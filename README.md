# 📊 Data Analysis & Visualization Program

A simple **Python-based Data Analysis and Visualization Program** built using **Pandas** and **Matplotlib**.

This project allows users to **load, explore, clean, analyze, visualize, and save data** through an easy menu-driven interface.

---

## ✨ Features

- 📂 Load datasets from CSV files
- 🔍 Explore dataset structure
- 📋 Display first and last rows
- 🧾 Display column names and data types
- 📐 Check dataset shape
- 🔄 Sort and filter data
- 🧹 Handle missing values
- 📊 Generate descriptive statistics
- 📈 Create different visualizations
- 💾 Save generated plots as image files
- 🖥️ Simple menu-driven interface

---

## 📌 Data Analysis Operations

### 1. Load Dataset

Users can enter the path of a CSV file and load the dataset into the program.

### 2. Explore Data

The program allows users to view:

- First 5 rows
- Last 5 rows
- Column names
- Data types
- Basic dataset information

### 3. DataFrame Operations

Users can perform different DataFrame operations such as:

- Display dataset shape
- Display column names
- Sort data
- Filter data based on conditions

### 4. Handle Missing Data

The program provides options to:

- Display rows containing missing values
- Fill missing values using mean
- Drop rows with missing values
- Replace missing values with a specific value

### 5. Descriptive Statistics

The program generates statistical information including:

- Count
- Mean
- Standard deviation
- Minimum value
- Maximum value
- Quartiles

## 📊 Data Visualization

The project supports the following visualization techniques:

| Visualization | Purpose |

| 📊 Bar Plot | Compare values between categories |

| 🔵 Scatter Plot | Show the relationship between two variables |
| 🥧 Pie Chart | Show category proportions |
| 📉 Histogram | Understand data distribution |
| 📚 Stack Plot | Compare multiple values |

## 🎯 Project Objective

The main objective of this project is to understand the basic workflow of data analysis:

> **Load → Explore → Clean → Analyze → Visualize → Save**

This project provides practical experience with **Pandas DataFrames, data cleaning, descriptive statistics, and data visualization**.

---

## 🚀 Learning Outcomes

After completing this project, users can understand:

- How to work with CSV datasets
- How to use Pandas for data analysis
- How to explore and manipulate DataFrames
- How to handle missing data
- How to generate descriptive statistics
- How to create different charts using Matplotlib
- How to save visualizations as image files
